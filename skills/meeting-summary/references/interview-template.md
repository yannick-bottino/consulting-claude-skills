# Interview Template

Ce template est concu pour les entretiens de recrutement : entretiens techniques, entretiens culture fit, entretiens managers, debriefs d'entretien.

## Structure du document

```
# Interview - [Nom du candidat] - [Poste] - Date

---

## Informations candidat

| Champ | Valeur |
|-------|--------|
| Nom | |
| Poste vise | |
| Interviewer(s) | |
| Etape du process | Screen / Technique / Manager / Final |
| Duree | |

## Impression generale

2-3 phrases de synthese. C'est le paragraphe qu'un hiring manager lit en premier.

## Competences evaluees

### [Competence 1]

- **Niveau observe :** Fort / Correct / Insuffisant
- **Elements factuels :** Ce que le candidat a dit ou demontre qui justifie cette evaluation.

### [Competence 2]

(...)

## Points forts

- Point fort 1 : detail factuel
- Point fort 2 : detail factuel

## Points d'attention / Risques

- Point d'attention 1 : detail factuel
- Point d'attention 2 : detail factuel

## Reponses aux questions cles

### Q : [Question posee]
**Reponse du candidat :** Synthese

(repeter pour chaque question significative)

## Motivations et attentes du candidat

- Ce que le candidat a exprime comme motivation
- Ce qu'il cherche (salaire, remote, evolution, etc.) si mentionne

## Recommandation

Go / No-go / A approfondir en prochain entretien

**Justification :** 1-2 phrases.

## Prochaines etapes

- **Nom :** Action

## Action Items

- **Action courte et autonome**
```

## Instructions specifiques

### Competences evaluees

Ne liste que les competences qui ont effectivement ete evaluees ou discutees pendant l'entretien. Ne cree pas de categories vides. L'evaluation du niveau doit etre justifiee par des elements concrets du transcript, pas par une impression.

### Points forts / Points d'attention

Toujours appuyes par des faits du transcript. "Le candidat a bien repondu" n'est pas suffisant. "Le candidat a decrit en detail son experience de migration de monolithe vers microservices chez X, avec des metriques de performance" est bien.

### Recommandation

Si le transcript ne contient pas de recommandation explicite de l'interviewer, omets cette section ou note "A discuter en debrief".
