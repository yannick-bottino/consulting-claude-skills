# Sales Call Template

Ce template est concu pour les appels commerciaux : calls de decouverte, demos, negociations, follow-ups pipeline.

## Structure du document

```
# [Compte / Prospect] - Type de call - Date

---

## Contexte du deal

| Champ | Valeur |
|-------|--------|
| Compte | Nom |
| Interlocuteurs | Noms + roles |
| Stade pipeline | Discovery / Demo / Negotiation / ... |
| Montant estime | Si mentionne |
| Echeance | Si mentionnee |

## Resume du call

2-3 phrases sur ce qui s'est passe et ou on en est.

## Besoins identifies

- Besoin 1 : detail
- Besoin 2 : detail

## Objections et freins

- **Objection :** Detail + reponse apportee (ou a apporter)

## Signaux d'achat / Signaux de risque

### Positifs
- Signal 1

### Negatifs
- Signal 1

## Concurrence mentionnee

- Concurrent X : ce qui a ete dit

## Prochaines etapes

- **Nom :** Action + deadline

## Action Items

- **Action courte et autonome**
```

## Instructions specifiques

### Contexte du deal

Remplis le tableau avec les informations deductibles du transcript. Si un champ n'est pas mentionne, omets-le plutot que de deviner.

### Besoins identifies

Extrais les besoins explicites et implicites du prospect/client. Un besoin implicite est un probleme mentionne sans qu'il soit formule comme un besoin. Par exemple, "on perd du temps sur les reportings" = besoin d'automatisation du reporting.

### Objections et freins

Tout ce qui a ete souleve comme frein, doute ou objection. Inclus la reponse qui a ete donnee pendant le call (si elle a ete donnee). Si l'objection est restee sans reponse, note-le.

### Signaux d'achat / Signaux de risque

Les signaux positifs sont : questions sur le pricing, demande de timeline d'implementation, mention d'un budget, implication de decision-makers, enthousiasme sur une feature.

Les signaux negatifs sont : reponses evasives, report de decision, mention de concurrents en evaluation, absence du decision-maker, questions sur la possibilite de ne pas avancer.

### Concurrence mentionnee

Si aucun concurrent n'est mentionne, omets cette section.
